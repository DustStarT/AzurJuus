# JUUS 界面规范与验证

参考输入为 `Screenshot/` 的四张原型截图及 `UI演示.mp4`。界面保留青蓝侧栏、大头像列表、浅色半透明面板，私聊使用角色立绘，群聊使用统一浅色场景。

## 布局

- 桌面侧栏基础宽度 108px，1600px 以上使用 130px；主区采用受视口高度约束的网格。
- 私聊和群聊：左会话、右消息；输入区固定在面板底部，会话与消息各自滚动。
- 动态总览：横向大卡片组成纵向列表；详情左图右文，评论独立滚动。
- 工作记录位于右抽屉，任务状态、错误和审批直接来自持久化事件。设置为独立对话框。
- 1100px 以下收紧间距，800px 以下切换单列会话。减少动态效果同时支持系统偏好与用户设置。

## 视觉与动画

核心色为 `#50c4e5`（强调）、`#4b9cbd`（次强调）、`#3e4b58`（正文）。统一变量、媒体查询及组件样式位于 `frontend/theme.css`，由 Prettier 格式化。

按钮反馈为 150ms；抽屉位移为 220ms；设置对话框透明度 180ms、位移 220ms。过渡主要使用 transform/opacity。动态详情进入动画只随详情切换触发，流式消息不重建页面。动效脚本记录重复开关面板期间的帧间隔、长任务及内存/DOM 样本。

Vue 使用稳定消息 ID；流式事件按 animation frame 批量刷新；初始渲染最近 100 条消息，更早内容按批加载。输入区保留 composition 状态，中文选字 Enter 不触发提交。角色图片集中预加载，头像有失败占位，桌面浏览器配置提供磁盘 HTTP 缓存。

## 产物

> 开源前已精简 `validation/`：交互录屏（`.webm`）、多分辨率重复截图、JUnit 报告与验收 JSON 已删除，仅保留 6 张展示用截图。下文提到的产物路径属于精简前的验收记录。

`validation/ui/` 包含私聊、群聊、朋友圈总览、详情、设置和抽屉截图以及交互录屏。`tools/ui_acceptance.py` 复现交互与 1280×720、1600×900、1920×1080、1024×576、853×480 的布局检查。

同一脚本还检查 350 条消息的按批加载、60 段流式事件与工作区刷新并行时的完整性，以及输入焦点和选区保持。静态对照截图等待转场结束；性能测量保留真实动画，不关闭动效。

`validation/qt/` 包含实际 PySide6/QWebEngine 截图及 1.0、1.25、1.5 应用缩放报告。应用缩放测试不能替代所有显示器、GPU 和 Windows 系统 DPI 组合；浏览器帧时间也不能直接代表桌面 GPU 的持续性能。
