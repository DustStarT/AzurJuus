## 已修复的主要问题

- 生产消息和任务不再进入旧的固定五轮或模拟完成执行链。旧链仅由显式 `legacy-test` 环境用于历史兼容测试；生产旧执行接口返回 409。
- 成员不能仅凭文本汇报完成。交付引用自己的成功核验调用，每个产物必须读取且哈希保持一致；下载时再次校验。失败或拒绝操作需要修正记录与后续证据。
- 工具请求与响应在上下文裁剪中成组保留；完整执行日志持久化，历史摘要可通过 execution_history 定位完整分页记录。长单行文本、长文档及网页内容有继续读取入口。
- 审批绑定具体调用；拒绝返回执行者，暂停中止等待。重启使旧审批失效，未知副作用需人工核验，不自动重放。
- 多成员执行失败会取消同批兄弟任务。命令与文件写入串行；原生线程退出前保留写锁。桌面任务释放前等待其工具退出。
- 用户和结果消息使用稳定 ID。任务完成但消息未写入时，启动恢复补投结果，防止重复消息或静默丢失。
- 模型错误明确传递，生产社交生成也不使用模板成功回退。本轮定位并修复 Hermes 自定义端点密钥未显式绑定导致的 401；最新 cloud-report.json 为实际 DeepSeek 成功任务。
- API Key 不再返回界面；Windows 使用 DPAPI。修复任意项目文件静态回退、非本地 Host 和跨来源写入入口。
- 前端不再整页重建；修复输入框被网格挤出视口、评论/发布/角色接口字段、人设编辑误用整批替换接口、窗口设置跨线程调用等问题。
- 自动动态与评论使用新的持久化通知通道；模型等待期间关闭数据库会话，任务启动时取消社交生成。修正 SQLite 无时区 UTC 值被解释成本地时间、导致动态过早到期的问题。
- 重启恢复遍历全部未完成任务，不受最近 200 条列表限制。工具事件持续保留成员阶段标识；非法参数也进入失败日志，未开始的审批中断不会误记为未知副作用。
- 用户补充在最后一轮结束时尚未消费会暂停并保存；继续后进入模型上下文。工作区刷新不再跳过 WebSocket 游标，流式输出期间保持焦点与选区。
- 桌面快捷操作使用受限的命名动作，重新检查焦点与控件快照；桌面、命令和文件写入共用串行锁。任务结束后关闭独立浏览器进程并释放 UIA 缓存，保留磁盘浏览器配置。

## 尚未满足的验收与边界

1. DeepSeek `deepseek-flash` 已通过本轮实际云端验收；此前的 401 已定位到自定义端点凭据映射并修复。其它模型、长时间复杂任务、云端模型驱动的任意浏览器/桌面操作仍不能由这些合成文件任务覆盖。
2. Explorer 早期验收曾因无法取得前台焦点而停止。加入 DPI 处理后最新实际验收已通过：新建窗口、UIA 定位、导航、选择、剪切粘贴移动与撤销恢复；`validation/desktop/report.json` 记录步骤。不同权限级别、锁屏、多显示器和其它专业软件仍不能由这一次成功覆盖。
3. 图像定位依赖用户明确配置支持图像的模型；扫描 PDF 仅标记 OCR 需求。没有任意专业软件/Office GUI 自动化承诺。
4. 程序执行不是 OS 沙箱。具体命令首次授权后具有当前用户权限；高风险命令检查只是补充，不能穷举脚本的全部副作用。浏览器点击与下载采用较保守的逐次确认。
5. 暂未做长达数小时的内存耐久测试或所有 Windows 系统缩放/多显示器组合。以保存的测量报告为准，不宣称所有机器稳定 60fps。
6. 技能目录与历史保留，已验证任务总结进入持久化检索；完整的自动技能提炼与质量评估仍有扩展空间。旧执行代码保留在显式兼容测试路径，未删除其历史测试覆盖。
