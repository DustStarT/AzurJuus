# 任务表达、逐句消息与用户资料

这是对人物认知第一轮实现的补充。改动已接入桌面使用的生产资源；是否更符合角色性格，仍应结合真实使用判断，不能把提示规则当作效果保证。

## 使用变化

- 新回复按完整句子逐段出现，不再逐字显示。句子之间停留约 650–1600 毫秒，依据文本长度调整；模型完成不会立即冲掉等待队列。段落可成为独立气泡，最多四个。代码块等待内容完整后显示，避免拆坏代码。
- 新气泡有 220 毫秒轻微位移与淡入，新增句子有 180 毫秒淡入。系统或应用的减少动态效果设置可关闭动画。历史消息直接显示，不重播。
- 当前停在聊天底部时，逐句呈现继续跟随滚动；向上阅读时保持位置。流式转为最终消息仍使用同一消息节点。
- 任务发言默认只说重要结果、阻碍、需要对方决定的事项，一般一两句话；完成时先给一到三句结论。用户要求过程或详细报告时再展开。此规则不会截断实际文本，也不会降低文件产物和工具验收要求。

## 我的资料与数据

设置新增“我的资料与数据”：修改自己的称呼，上传不超过 500KB 的 PNG、JPEG 或 WebP 头像，或恢复文字头像。保存后资料存在本地业务数据库，新执行请求从用户资料读取称呼。

| 操作 | 改变什么 | 保留什么 |
| --- | --- | --- |
| 清空聊天和工作列表 | 删除聊天正文，清空会话预览，归档已结束工作记录 | 长期记忆、技能、配置、实际文件与任务审计 |
| 忘记长期经历与关系判断 | 排除经历、承诺、关系推断及用户关系说明，清空长期检索 | 现有聊天、技能、配置、实际文件；保留的聊天仍可作为上下文 |
| 初始化系统 | 恢复种子角色与设置，清空业务历史、认知、方法成长和运行存储 | 实际工作区文件；历史备份及诊断日志可能保留，不是磁盘安全擦除 |

清理需要输入“确认清理”；存在运行、暂停或待审批任务时拒绝操作，请先停止任务。初始化后通常需要重新配置模型。程序不会在开发测试中清理你的真实数据。

## 关系如何参与协作

旧实现主要依靠异步反思产生关系判断；在没有反思结果时，协作上下文很容易退化为只有姓名。现在增加两种来源：

1. 人物自己可见的共同交流与任务经历，形成带来源标识的熟悉程度说明。共同参与不等于能力优秀，也不自动等于亲密；未知的原作关系不凭空补造。
2. 用户在“方法与成长 → 经历与关系 → 设定关系”填写的关系说明。例如常合作的同事、可以直接指出问题。这是用户设定，不是伪造的历史事件；留空保存可以移除。

关系有方向：能代对豪的认识不会自动变成豪对能代的认识。定向讨论只使用收信者自己的关系信息，不把发送者的私人判断交给对方。人物停用认知后不再注入这些信息；关系读取故障也不会阻断讨论回复。

## 关键代码路径

| 文件 | 负责什么 |
| --- | --- |
| `frontend/SpeechBubbles.vue` | 缓冲完整句子、逐句队列、稳定段落节点、动画与卸载清理；已完成消息不强制排空队列 |
| `frontend/App.vue` | 接收句子呈现事件，按用户原滚动位置决定是否跟随 |
| `backend/personality.py` | 默认简短任务表达；表达规则与执行验收分开 |
| `backend/cognition.py` | 从个人可见经历得到共同经历说明，存取用户关系设定，版本化通知 |
| `backend/collaboration_dialogue.py` | 按收信者的关系上下文回应具体同伴 |
| `backend/personal_settings.py` | 用户资料验证、记录与记忆清理，以及活动任务保护 |
| `backend/app.py`、`backend/services.py` | 初始化时清理新增认知表和运行存储；同一业务事务写入旧事件屏障，避免清理中断后旧经历重新投影 |

称呼和头像接口是 `POST /api/profile`；清理是 `POST /api/system/clear/records`、`POST /api/system/clear/memory`；初始化沿用 `POST /api/system/reset`。关系编辑使用 `POST /api/actors/{id}/relationships/{peer_id}`，不会开放为角色可调用的工具。

## 验证边界

本轮后端完整回归 89 项通过；随后增加关系编辑和初始化屏障，相关认知、协作、资料管理测试共 22 项通过。前端类型检查及生产构建通过。浏览器验收脚本新增逐句间隔、资料保存、关系编辑与记忆清理检查，结果见 [交互报告](../validation/ui-messages/report.json)。

仍有限制：共同经历检索使用近期 100 条候选，不是完整社会认知模型；模型可能仍会偶尔长篇汇报。未在本轮取得真实云端人格自然度对照评分，不能宣称机械感已经被彻底消除。
