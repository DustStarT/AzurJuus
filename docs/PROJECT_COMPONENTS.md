# 项目目录：哪些必须保留

| 内容 | 当前用途 | 处理方式 |
| --- | --- | --- |
| `backend/`、`server.py` | 本地 HTTP 服务、任务调度、工具权限、数据库、人格与表达 | 桌面运行必需；“后端”不等于远程服务器 |
| `desktop.py`、启动批处理 | PySide6 窗口、后台服务启动与退出 | 保留 |
| `frontend/`、`dist/` | Vue 源码与桌面实际加载的构建结果 | 源码开发需要；运行需要 dist；不能同时删除 |
| `.vendor/hermes-agent`、`hermes.lock.json` | 锁定版本的实际执行核心 | 保留，不手改依赖内部代码 |
| `.venv/` | 当前 Python 运行环境 | 本机运行需要，重装可重建 |
| `node_modules/` | 前端开发依赖 | 只运行已构建桌面时不必安装，开发构建需要 |
| `.azurjuus/`、`backups/` | 真实聊天、配置、运行审计和备份，也含隔离验收目录 | 不作为“冗余代码”删除；清理数据须区分真实数据和测试目录 |
| `deployment/optional/` | Docker 服务配置与可选驱动依赖 | 已从根目录移出，不参与默认桌面启动 |
| `tests/`、`tools/`、`validation/` | 回归、安装与验收复现、证据 | 保留可复现工具，不以删除测试精简产品 |
