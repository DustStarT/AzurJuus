# 人格、社会关系与成长系统：2026-09-16 实施记录

本轮已接入生产链并完成下面列出的验证，尚未完成整轮人格效果验收。技术解释见 [认知系统讲解](COGNITION_GUIDE.md)。

## 已交付

| 计划部分 | 当前实现 | 边界 |
| --- | --- | --- |
| 统一人物状态 | 五张认知表、迁移前备份、来源事件、消费游标、幂等收件和发件记录 | 不从历史摘要补造心理经历 |
| 经历与身份连续 | 私聊、任务、讨论、朋友圈使用人物自身可见的认知上下文 | 最近 100 条候选中选取最多八条；不是完整语义检索 |
| 关系与反思 | 有方向的来源判断、合作倾向、短反思、版本冲突检查 | 对他人的认识仍是简短判断，不是完整心智推演 |
| 协作讨论 | 问题、建议、异议、答复、解决状态；两轮上限；工具失败触发受控求助 | 不允许成员直接重写他人职责和整张依赖图 |
| 消息表达 | 最多四段气泡；流式与最终消息使用稳定节点；私聊避免混入其他角色人格 | 分段自然度仍取决于模型和提示 |
| 事件驱动社交 | 真实经历触发、全局间隔、评论上限、工作资料隔离、防评论循环 | 被前台工作打断的分享机会可能跳过，不补演 |
| 方法成长 | 目录清单、文件分类两个任务族；三个场景各运行原方法与候选，共六次隔离验收 | 其他任务族缺少验收器时只保留候选 |
| 方法管理 | 试用、启停、回退、来源证据；公有发布需秘书复核与用户确认 | 回退恢复可用方法选择；尚非任意历史版本的完整快照仓库 |
| 用户管理 | 查看状态、经历和关系；纠正、忘记、清除成长、单人物开关 | 忘记经历不会删除工具审计事实 |

补充修复：关闭后台反思不再连带关闭技能试用；状态开关与重置会发送带版本的变化事件；方法控制接口兼容尚无生命周期字段的旧数据。

## 本轮验证结果

环境：当前 Windows 开发机，项目虚拟环境、Vue 构建工具及 PySide6/QWebEngine。测试使用独立数据，没有以真实历史数据库作为可破坏的测试夹具。

| 验证 | 结果与证据 | 能证明什么 |
| --- | --- | --- |
| 后端全量测试 | 83 项通过，124.36 秒；[测试结果](../validation/cognition-pytest.xml) | 当前收集范围内的执行、恢复、权限、社交和认知回归 |
| 认知专项补充 | 15 项通过，9.84 秒；`tests/test_cognition.py` | 包含全量测试启动后新增的两项：配置变化事件、讨论轮数和解决状态；不能与 83 相加作为不重复测试数 |
| 前端类型与构建 | `npm.cmd run build` 通过 | 类型检查与生产资源构建 |
| 浏览器交互 | [报告](../validation/ui-messages/report.json)、[人物面板截图](../validation/ui-messages/mind-panel.png) | 60 段流式事件到最终持久化；597 次帧采样中节点缺失、替换、空白均为零；中文输入、焦点、选区、经历纠正与忘记、清理记录及删群 |

测试仍出现三个上游弃用警告，涉及 Starlette/AnyIO 和 Uvicorn/WebSocket；本轮没有把警告当成任务失败或隐藏异常。

## 尚未完成的验收

1. 四种条件、24 场景各三次的真实云端人格比较，以及 30 段连续互动。此前批量请求被自动审批拒绝，理由是 Codex 使用额度限制；未通过其他入口绕过。准备材料不等于已执行评测。
2. 至少两名评阅者的匿名对照评分。没有取得自然度与行为辨识胜出率，不能宣称达到 65%。现有比较工具使用合成记忆和重建基线，只能算提示层实验，不能替代完整生产系统消融实验。
3. 新关系机制下的真实云端多成员纠错、六次技能试用与正式任务回归。离线测试已运行真实文件工具和模型桩，但本轮桌面云端验收只覆盖普通聊天和文件任务。
4. 认知处理第 95 百分位低于 100ms、退出第 95 百分位低于五秒、持续运行内存及帧时间测试。消息节点连续性通过不等于已经测得全界面稳定 60fps。
5. 原作人物材料的外部来源核对。当前五名人物行为样例来自本地材料及作者解释，未冒充官方核验结论。

承诺目前从人物自己说过的话中提取；自动判断兑现与失约仍有限制。持续成长、长期同质化和关系合理性需要上述连续互动及人工评价，不能仅靠单元测试保证。

## 如何使用与回退

从成员资料进入“方法与成长”，切换“经历与关系”即可检查来源并纠正理解。先用小任务观察角色是否记得自己的承诺，再查看合作判断是否有真实经历支撑。

全局开关 `AZURJUUS_COGNITION_ENABLED=0` 可停用新认知行为，保留新数据。`AZURJUUS_REFLECTION_ENABLED` 与 `AZURJUUS_SKILL_TRIALS_ENABLED` 分别控制后台反思与试用。功能存在和离线验证通过不代表人格效果已经验收。
