# 角色资源

## 当前资料覆盖与运行方式（2026-09-21）

十二名基础角色有结构化资料和六类原创终端对话示例，但这些仍是简要解释，不能视为完整原作人物模型。数据库内已生效的角色卡及用户覆盖优先；修改本目录文件不会静默覆盖它们。全局世界观目前只有少量概括条目，剧情经历也不会在安装后自动凭空生成。

关系研究现可从 [原作聊天](https://wiki.biligame.com/blhx/聊天)、[JUUs 动态](https://wiki.biligame.com/blhx/JUUs动态)、[剧情文字版](https://wiki.biligame.com/blhx/碧蓝回忆录文字版) 与角色页的相关活动出发，按索引类别选取有限页面；模型提取的关系和人物背景理解必须带可在网页资料中逐字找到的引文。背景理解保存在 `originalMindNotes`，只作为可纠正的原作资料解释进入对话和任务提示，不能当作本应用里发生过的共同经历。已读取的公开资料会缓存；站点临时失败时可使用旧缓存，但研究标记为“部分完成”并保留抓取时间。索引检索是有上限的抽样，不保证覆盖每一篇剧情。关系图的“全部重新检索”仅排队当前角色名单，并展示批量进度。

[Wiki 表情包](https://wiki.biligame.com/blhx/表情包) 混有游戏聊天、官方动态和社区内容；自动目录只读取明确的游戏聊天或官方分区。人物可使用目录中其他角色形象的表情，图片中的人物不会因此成为系统成员。选中表情后才从 Wiki 下载媒体到本地缓存；下载失败只影响表情显示。Wiki 临时不可达时使用随项目保存的已筛选目录。

本目录存放 AzurJuus 的角色人设素材。角色资料、可编辑的世界背景和运行时关系各有用途：本目录保存人物材料，`resources/world/global.json` 保存整体世界观，应用数据库保存用户修改与共同经历。

| 文件 | 内容 | 用途 |
| --- | --- | --- |
| `<角色名>.json` | 结构化角色资料：阵营、舰种、稀有度、立绘 URL、角色设定、台词表、主题配色 | 创建角色账号、生成头像与界面主题 |
| `<角色名>.prompt.md` | 由 JSON 提炼的人设提示词：角色定位、说话与互动风格、扮演要求 | 导入材料；修改文件不会自动覆盖数据库中的生效人设 |

十二人目标名单的阵营和已核对关系见 [版本化世界书](../world/juus.json)，版本 `juus-world-2026-09-20.1`。八条方向关系分别注明说话者、对象和台词场景；检索话题词是作者解释，不作为原作逐字设定。新增原始抓取仍存在皮肤情境混用、彩蛋台词被链接标签切开的情况，不能直接当作整理完毕的终端角色卡。

关系仍需逐条核实。资料研究可使用 Wiki 的原作聊天、JUUs 动态、剧情回忆录及《微速航行》页面；只有引用能支持具体互动时才写入关系。像“一行人”这样的代称，需要补查参与者，不能直接套用常见组合。
研究会读取角色页明确列出的“相关活动／相关剧情”，再查同名剧情文字版；重樱等剧情中的和谐名以 Wiki 舰船名称对照表映射到当前名单。信浓页的“蝶海梦花”与剧情里的“鵗”已在隔离的真实模型验收中核对。资料页面可能暂时返回 567，研究状态会记录读取失败，不据此补造关系。

### 当前生效链

聊天终端基础卡目前覆盖计划中的十二名角色，版本 `terminal-2026-09-20.1` 定义在 `backend/characters/terminal_characters.py`。每人包含六类原创终端示例。人物面板中的“角色卡”显示实际生效文本、版本及差异。应用更新时保留已记录的用户覆盖；“恢复基础版本”才明确替换覆盖内容。尚未应用版本卡的账号继续使用数据库旧人设，不会因为更新文件而静默改变。

原始抓取材料可能混有皮肤、誓约及特殊情境台词，不能整体当作普通聊天示例。新基础卡的六组终端示例是作者编写的表达参考，不是游戏原文。关系条目另存出处；没有资料支撑的关系不推定为亲密。

实现与验收限制见 [聊天终端改造记录](../../docs/TERMINAL_IMPLEMENTATION_20260917.md)。

## 重新抓取或添加角色

数据由 `tools/blhx_character_import.py` 抓取并生成本目录下的文件：

```powershell
.\.venv\Scripts\python.exe -X utf8 tools\blhx_character_import.py 信浓
.\.venv\Scripts\python.exe -X utf8 tools\blhx_character_import.py https://wiki.biligame.com/blhx/能代 --refresh
```

参数为角色名或完整 wiki 链接；`--refresh` 会忽略本地缓存重新抓取。抓取结果只写入本目录，不会改动其他资源。
