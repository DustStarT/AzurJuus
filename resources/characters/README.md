# 角色资源

本目录存放 AzurJuus 的角色人设素材，每个角色由两个文件组成：

| 文件 | 内容 | 用途 |
| --- | --- | --- |
| `<角色名>.json` | 结构化角色资料：阵营、舰种、稀有度、立绘 URL、角色设定、台词表、主题配色 | 创建角色账号、生成头像与界面主题 |
| `<角色名>.prompt.md` | 由 JSON 提炼的人设提示词：角色定位、说话与互动风格、扮演要求 | 导入材料；修改文件不会自动覆盖数据库中的生效人设 |

当前材料包含原有八人，以及新抓取的阿贺野、武藏、英王乔治五世、约克公爵、贾维斯、标枪、七省，共十五份资料。材料文件不等于已启用账号。新增七人可在群聊成员面板的“人物目录”中预览终端卡，再选择“启用聊天与社交”；不会自动入群或获得工具任务权限。重新连接已有角色保留用户人设、头像和附加状态。

十二人目标名单的阵营和已核对关系见 [版本化世界书](../world/juus.json)，版本 `juus-world-2026-09-20.1`。八条方向关系分别注明说话者、对象和台词场景；检索话题词是作者解释，不作为原作逐字设定。新增原始抓取仍存在皮肤情境混用、彩蛋台词被链接标签切开的情况，不能直接当作整理完毕的终端角色卡。

### 当前生效链

聊天终端基础卡目前覆盖计划中的十二名角色，版本 `terminal-2026-09-20.1` 定义在 `backend/terminal_characters.py`。每人包含六类原创终端示例。人物面板中的“角色卡”显示实际生效文本、版本及差异。应用更新时保留已记录的用户覆盖；“恢复基础版本”才明确替换覆盖内容。尚未应用版本卡的账号继续使用数据库旧人设，不会因为更新文件而静默改变。

原始抓取材料可能混有皮肤、誓约及特殊情境台词，不能整体当作普通聊天示例。新基础卡的六组终端示例是作者编写的表达参考，不是游戏原文。关系条目另存出处；没有资料支撑的关系不推定为亲密。

实现与验收限制见 [聊天终端改造记录](../../docs/TERMINAL_IMPLEMENTATION_20260917.md)。

## 重新抓取或添加角色

数据由 `tools/blhx_character_import.py` 抓取并生成本目录下的文件：

```powershell
.\.venv\Scripts\python.exe -X utf8 tools\blhx_character_import.py 信浓
.\.venv\Scripts\python.exe -X utf8 tools\blhx_character_import.py https://wiki.biligame.com/blhx/能代 --refresh
```

参数为角色名或完整 wiki 链接；`--refresh` 会忽略本地缓存重新抓取。抓取结果只写入本目录，不会改动其他资源。
